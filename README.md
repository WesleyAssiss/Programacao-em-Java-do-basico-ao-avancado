# Programação em Java: Do Básico ao Avançado

Este repositório documenta meu progresso e aprendizado no desenvolvimento Java, com base em um curso completo da Udemy. Ele serve como um portfólio prático, demonstrando minhas habilidades em programação, desde os conceitos fundamentais até técnicas avançadas de Orientação a Objetos e estruturas de dados.

-----

### Sobre o Projeto

Este projeto é um resultado prático de um curso de programação Java da plataforma Udemy. O objetivo é registrar meu aprimoramento contínuo na linguagem, aplicando os conhecimentos adquiridos em cada seção e desenvolvendo uma base sólida para a criação de aplicações.

-----

  * **Seção 12**: Classes Abstratas

  * **Seção 17**: Conhecendo o Java Lang
